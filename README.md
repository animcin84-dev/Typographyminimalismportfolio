# DANIYAL Typography Portfolio — V7

V7 keeps the typography-first system from V6 and art-directs the project previews instead of adding more global effects.

## What changed
- HELIX preview is now a verification/reconciliation console scene.
- DALA2 preview is an evaluation/data scene.
- JARVIS preview is a command → multi-action AI OS scene.
- GARGANTUA uses one real NASA GSFC black-hole reference image, with visible credit, instead of a random stock image.
- QADAM AI preview is a grounded contract/evidence scene.
- The same scenes carry through the project → case-study FLIP transition.
- Contact now includes clickable email and phone links.
- Mobile styles were tuned for all five new previews and the contact links.

Open `index.html` directly. Internet access is only needed for the NASA reference image and Google Fonts; all interactions remain in the single HTML file.


### V7.1 fix
GARGANTUA media is now embedded as a self-contained SVG data URI instead of a remote image, eliminating broken-image/alt-text failures in local or sandboxed previews.
